# 独立高云与分段空气输运（2026-10-23）

本轮从当前 HEAD `2b18d56ebe0b6b26150d18da7e50326b1f946925` 继续。工作树起始干净；没有回退到早期审查基线，也没有覆盖其它修改。Cesium 固定为 1.146.0 / WebGL2。

## 已确认的根因

旧代码已有先塑形再生成 mip 的 `CirrusField`，不能把它误报为所有纤维都在 mip 后阈值化。但高云仍用固定世界 X 拉伸域、一个各向同性 mip 等级，慢变云带也随横向纤维一起被平均；之后的 envelope 截断不能保存当地覆盖和平均透射。旧垂直剖面没有归一化，消光是固定的 `.26 / km` 倍率，改厚度就同时改了柱光学厚度。真实 WebGL 反例把厚度从 0.5 改到 3 km，柱 tau 近似变为六倍。

旧高云虽已绕过 powder，仍复用水滴的光深/散射阶次，并用有上限的平面柱深近似。所有云最终共用一个 `weightedDistance` 进行空气透视，无法区分前后层，也没有正确处理空气和云在同一个积分区间内的竞争消光。

## 两个独立预设

`highCloudPresets` 与界面的高云预设提供：

| 参数 | Cirrus | Cirrostratus |
| --- | ---: | ---: |
| highType | 0 | 1 |
| highCoverage | 0.45 | 0.85 |
| highOpticalDepth（τᵥ） | 0.35 | 0.28 |
| highThickness / km | 1.5 | 1.2 |
| highAnisotropy（HG g） | 0.78 | 0.72 |
| highAlbedo | 0.98 | 0.99 |
| highMultiple（弱各向同性补偿） | 0.12 | 0.08 |

Cirrus 使用稀疏纤维材质。球面标量流函数的表面旋度定义当地组织方向，叠加大尺度弯曲和公里尺度拖尾；方向随世界位置变化。局地剪切来自流函数梯度变化。极区没有经纬度切平面分支；流速趋于零时，流函数扰动及其导数一同衰减，材质连续变为各向同性。地面斜视检查曾暴露中间实现的过长相关尺度和等间距重复云带；最终域缩短沿风相关长度，并用不与纹理周期重合的连续势函数改变间距，完整导数仍进入足迹过滤。风动仍以连续球面旋转平流为主；这不是气象风场或流体演变模拟。

Cirrostratus 使用缓慢变化的连续光学薄幕，不对细纤维噪声重新阈值化。两种预设均能独立于主云存在，种子、时间和风冻结时不随 quality 改变空间场。

## τᵥ、光程与过滤

`highOpticalDepth` 是单位天气/材质掩码处的**垂直柱光学厚度**。当地柱深为 `τᵥ × weather × material`，不是每公里密度。高度剖面为 `f(h)=30 h²(1−h)²`，在 `[0,1]` 上积分为 1，消光为 `τ_local f(h)/thickness`。主射线仍沿排序、深度裁剪后的有限球壳区间积分，未用 `τᵥ / cos(theta)` 替代地球边缘的真实几何。

高云直接光使用独立冰云单次 HG 散射、显式 albedo 和弱各向同性补偿；不使用积云 powder、底部压暗或体素内部遮蔽。光线方向的自阴影用有限球壳剖面积分、保持当地柱深不变，是明确的局地近似，不是跨云层阴影。

原 64³ RGBA8 材质及 mip 保留，通道现存 `m`、`1−exp(−4m)`、非空概率和薄幕倍率。它们都在线性空间平均，先完成材质塑形，再过滤。非空概率指源材质 `m>0` 的面积，不等于 `P(T<0.9)`。

新增：

- `127×64×64 RGBA8` 单轴 mip atlas：横向尺寸按 64、32、16、…、1 缩小，沿风两个维度保持 64；共 **2,080,768 B**。
- `64×64 RGBA8` 横向完全平均后的云带统计及完整二维 mip：**21,844 B**。

新增固定存储 **2,102,612 B = 2.0052 MiB**。固定云纹理合计约 **15.56 MiB**。atlas 的硬件 level 0 只是手动 mip 的存储地址；真正选择的材质等级由足迹连续决定，没有锁定原始材质 LOD0。横向、沿风、屏幕两个方向及沿射线跨度使用完整映射 Jacobian（含拖尾变形导数）。每次最多 4×4 个子足迹，所有 quality 同预算；局部缓存复用同一云柱。跨越单轴周期时连续转入二维云带统计，避免把整个材质压成 1³。

由过滤后的平均消光、T(4) 和非空面积拟合条件 Gamma 光深分布，估计未解析细丝的平均透射。远景使用有限球壳的剖面积分来确定光学尺度；0.08–0.8 km 足迹之间分别完成两种表示的 L/T，再连续混合。该闭合仍不是每条子射线的完整光程相关性，尤其在长掠射和部分云柱上。

## 空气与云的分段合成

每段返回不含背景的 `L、RGB T、clearAirL、RGB clearAirT、cloudT`。每个样本同时计算空气与云：总消光为 `sigma_air + rho_cloud`，源项为 `j_air + rho_cloud S_cloud`，使用解析常系数区间积分。空区体素跳过仍保留空气积分；不增加原主射线步数预算。

背景已含整条清空大气的散射和透射，故不能直接再叠一次完整空气。对每段取 `Cseg = Lmixed − cloudT × Lclear`。按前后关系将 `Tair_prefix × Cseg + Lair_prefix × (1−cloudT)` 加入云输出，最终仍只做 `C + cloudT_total × background`。段间空气用同一 Hillaire 积分器推进。零云严格保留背景，空气透射始终为 RGB。提前停止不透明云时仍补全清空空气段，保证减项端点一致。

这在所用区间离散化及“清空大气源项不受云阴影改变”的前提下成立。大气的多重散射 LUT 仍来自清空大气；没有计算云投到空气中的体积阴影。Cesium 地表仍为 LDR 有效线性恢复，自定义天空、日月和云继续使用未截断 HDR，最后统一显示映射。RGBA8 编码、深度裁切、WGS84 距离换算、球壳排序、当地天空照明、逐点太阳透射、近景体素与资源销毁均保留。

## 验证方法与复现

运行 `npm test`、`npm run build`，然后：

```sh
node scripts/build-validation.mjs . artifacts/high-cloud-current
npx vite preview --host 127.0.0.1 --port 4180 --outDir artifacts
```

真实浏览器打开 `/high-cloud-current/tests/high-cloud-gpu.html` 及其它 GPU 夹具。原始 JSON、截图、元数据与本地画廊位于忽略目录 `artifacts/high-cloud-*`，不提交生成的 Cesium 资源或图片。

固定场景：RTX 5080 / Chrome / ANGLE D3D11；seed 13，风角/高云风角/演化均 0，UTC 2026-06-21T17:00Z，曝光 8，垂直 FOV 60°，drawingBuffer 1920×1080，medium scale 0.65。前后同机位：云间 7 km / heading 245° / pitch 24°；全球 17000 km / heading 0° / pitch −90°；经纬度均 −97.52° / 35.46°。高云单独对照用主云 coverage=0、高云 coverage=0.65；这是隔离实验，叠加场景另行保留主云。新旧材质和 τ 定义不同，场景截图不是同密度场微基准。

高云数值参考使用 8 个固定世界区域、64×64 子射线、每条 48 个高度样本，下采样线性 L/T，并以 128×128 检查空间参考收敛。薄幕与纤维分别检查近景、0.8 km 和 27.963 km 足迹。切线与壳边界使用 2048 步剖面参考。空气共存回归使用有色空气、两个不同云源、前后清空区间，比较解析的分段物理解。

## 固定画面与验收边界

截图、每图完整相机/UTC/参数 JSON、计时和回归 JSON 放在 `artifacts/high-cloud-*`；本地画廊为 `artifacts/high-cloud-report.html`。画廊只用 CSS 裁取未编辑的浏览器原始截图，原图可单独打开。主云为零的图用于隔离高云，高低云叠加图保持两个有效介质。

已实际检查的固定场景：

- 高云两种预设分别显示；全球仅主云、仅高云及两层叠加。Cirrus 可见弯曲、间断纤维与透空，Cirrostratus 为缓慢变化的薄幕。有限的程序化材质仍可能显出重复的组织方向，不宣称气象摄影级形态。
- 17000 km、1200 km、12.5 km、9.6 km 高云内、7 km 云间、800 m 地面。最终版的 24 秒连续镜头运行到 800 m 终点；记录起终点与固定机位，浏览器不支持导出 Blob 录像，**未完成逐帧时序量化**，不把静态截图当作整个镜头无跳变的证明。
- 日落长路径：当地手动太阳高度 0°、方位 245°；昼侧、夜侧和两极的全球视图；日期变更线 179.99°。这些画面没有观察到平面斜程形成的发散白环，数值路径参考另见上表。
- 薄幕后的太阳与月亮，均为 FOV 60°、coverage=1 的高云单独实验；月亮使用 UTC 2026-10-26T03:00Z，其余默认 UTC。两个圆盘仍可见，HDR 不经已截断显示值恢复；散射光晕是近似前向 lobe，不是 22° 冰晶光晕。
- 同一全球场景 medium→low→high→medium，空间天气位置一致，high 档保留正确的大气附件；质量仍改变实际足迹、采样误差和细节，未宣称逐像素一致。
- 同一 7 km 高云场景分别使用 RGBA16F 和强制 RGBA8，实际着色器与图像均通过，未见丢失高云或大气附件；RGBA8 仍有编码量化误差。

局部柱深保持不变的高云自阴影、条件 Gamma 闭合、有限空间 quadrature、长掠射/部分柱相关性、未受云阴影影响的大气源项和 Cesium 地表的 LDR 恢复均为剩余近似。Float32 世界坐标在细纤维边缘可造成亚米级投影偏移。其它 GPU、移动端、真实地形与 3D Tiles 未专项验证。
