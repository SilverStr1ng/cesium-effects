# 自然水云与原版对比

`water-clouds` 是第四个独立 effect，默认启用。`global-clouds` 保留为原版胞状云，界面「云层实现 · A/B 对比」切换两者。切换不改变相机、Cesium 时间、参数、画质或风场积累；只有选中模型的后处理通道启用。

## 方法与参考范围

本地 Three.js Sky Pro 2.2.1 的密度、光照与月夜配置用于理解算法结构。新实现采用公开体积云技术中的天气高度场、多尺度 Worley 形状、边界侵蚀、Beer–Lambert 消光、双瓣 Henyey–Greenstein 相函数和多阶散射近似。在 Cesium 中独立实现 GLSL；不是 Sky Pro 的 TSL 源码移植，不包含其商业源文件、噪声资产或预设参数。

与原版的主要区别：

- **形态**：连续天气高度场决定云顶；独立的三维细节扰动云顶和侵蚀上下边界。低覆盖柱的云底被抬升，形成空隙。使用地球球面上的天气场以及不同尺度、旋转后的三维采样，避免平面天气贴图重复。边缘柔度随采样足迹调整。当公里级细节小于像素时，平滑转为天气覆盖率对应的有效光学厚度，避免先平均噪声再阈值化造成轨道条纹。
- **白天光照**：沿太阳方向采样真实云密度的光学厚度，计算三个散射阶；天空漫射填充来自大气积分的天顶与低空方向。云顶高度和上方遮挡共同影响填充。
- **月光**：沿真实月亮方向单独积分云内遮挡与散射，包含月相、大气透射和地球遮挡。白昼跳过月光采样，深夜跳过太阳采样。月光不是原版的均匀蓝色补光。前景云的透射率同时衰减背景月盘。
- **风**：沿用真实秒推进的球面平流，叠加随高度变化的剪切及细节演化。

月光照云增益与大气面板的「月面亮度」独立：前者改变云中的月光，后者只调整月盘。月光能量包含展示用夜间适应增益，不是照度计标定结果；提高月面亮度不会把云染亮。太阳/月亮方向及月相仍由 Cesium Clock 对应的星历决定。

## 对比方法

1. 点击「白昼对比」或「月夜对比」。前者恢复默认云量 0.62、UTC 2026-06-21 17:00；后者使用 UTC 2026-10-26 03:00 的接近满月、云量 0.85 和面向月亮的地面机位。两者恢复其余默认天气，并暂停时间与风场。
2. 切换云层实现；视角与所有公共参数保持不变。
3. 月夜中将「月光照云」从 1 改为 0，可以隔离月光散射贡献。月盘仍显示，照云亮度降低。切回原版时该控制隐藏，原版保留历史光照作为对照。

测试场景 `/tests/cloud-scene.html` 增加 `model=water|cellular`、`time=ISO时间`、`view=moon`、`coverage` 与 `moonLight`。固定渲染缓冲 984×652，关闭相机交互，方便重复性能与画面对比。

## 结构与资源

- `WaterCloudEffect.ts` 提供新密度/光照模型；`CloudComparison.ts` 管理选择、共享参数和风场状态。
- 两个 effect 共用球壳相交、地形深度裁剪、积分与线性辐亮度合成，使用不同密度和光照模块。原版光照仅从 march 中拆出，计算保持不变。
- 两者各自拥有并释放纹理、后处理通道和事件订阅。为即时切换，两套固定纹理同时存在，约 6.28 MiB，另有依视口变化的渲染目标；CPU 噪声缓存共用。未选中通道不执行光线步进。

## 验证与限制

19 项 CPU 测试通过，包含对比预设的实际满月、地平线和夜侧检查。GPU 页面 `/tests/water-cloud-gpu.html` 的 12 项检查通过，使用真实密度及光照函数验证零云量、侵蚀上界、厚云核、风场演化、云下空隙、周期重复、轨道像素足迹稳定性、月相与月光方向、光学厚度衰减；原版 8 项 GPU 回归也通过。生产构建通过，实际浏览器已检查模型切换、三档编译、月光增益归零、厚云遮月、全球视角和云层独立开关。

当前采用空间重建，没有时域重投影。均衡/流畅档仍可能出现噪点或采样纹理；细节和光照质量不能等同于完整 Sky Pro。没有加入其卷云、月光体积光束或大气月光多重散射。云的天气形态仍为程序化模型；真实地形和 3D Tiles 深度遮挡没有新增专项验收。轨道视角仍能在海面看到既有大气通道的网格状明暗（关闭大气后消失）；它与本轮已处理的云噪声阈值条纹分属不同问题，未在此云 effect 中修正。

## 本机性能记录（2026-10-22）

Windows 内置 Chromium，生产构建的固定测试页，实际绘制缓冲 984×652，单个持续渲染标签页，2 秒预热 + 10 秒采样，风和时钟暂停。GPU timer query 测量整个场景。白昼两组使用相同云上机位、默认参数、seed 13 与 UTC 2026-06-21 17:00。

| 场景（均衡） | GPU 平均 | GPU P95 | 平均帧间隔 |
| --- | ---: | ---: | ---: |
| 原版胞状云，白昼云上 | 4.095 ms | 4.868 ms | 4.167 ms |
| 自然水云，白昼云上 | 3.852 ms | 4.512 ms | 4.167 ms |
| 自然水云，月夜对比机位，云量 0.85 | 3.103 ms | 3.831 ms | 4.169 ms |

白昼这一场景的新模型减少约 0.242 ms / 5.9% GPU 时间。两模型的密度分布与覆盖不同，不能当作同密度场下的算法微基准，也不能推广到所有机位。月夜一组时间、机位、云量不同，不与白昼推导加速比。原始结果保存在本地忽略目录 `artifacts/water-comparison-*.json`；本次未重新采样精细档耗时。白昼和月夜的新模型数据包含远景光学厚度过滤。
