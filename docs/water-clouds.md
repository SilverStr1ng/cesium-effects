# 自然水云与原版对比

`water-clouds` 是第四个独立 effect，默认启用。`global-clouds` 保留为原版胞状云，界面「云层实现 · A/B 对比」切换两者。切换不改变相机、Cesium 时间、参数、画质或风场积累；只有选中模型的后处理通道启用。

## 方法与参考范围

本地 Three.js Sky Pro 2.2.1 与用户提供的 [Cesium-Sky（dd83ed9）](https://github.com/Web3D-Archive/Cesium-Sky/tree/dd83ed9cdaf748e8c80adb0f7e82a2d1cc207538) 用于理解密度、光照和月夜算法结构。实现采用天气高度场、多尺度 Worley 形状、边界侵蚀、Beer–Lambert 消光、双瓣 Henyey–Greenstein 相函数和多阶散射近似。噪声独立生成，不包含参考工程的源文件或二进制噪声资产；不是 Sky Pro 的逐像素复刻。

与原版的主要区别：

- **形态**：连续天气高度场与正向胞状膨胀决定云顶；三维细节侵蚀上下边界。天气约束移除稀薄区域的云底，避免抬高硬质云底形成板块。近景边缘过渡半宽为云壳厚度的 0.055，默认约 209 米，比旧版约 25–46 米更宽；密实核心消光为 `16 × density / km`，默认 17.6/km，通透感依靠薄边而非把整朵云降低透明度。使用球面天气场及不同尺度、旋转后的三维采样，避免平面天气贴图重复。亚像素云瓣仍转为宏观有效光学厚度，避免轨道条纹。
- **白天光照**：太阳/月亮共用约 600 米范围的局部锥形采样，计算三个散射阶，超过 100 米的采样使用未侵蚀密度近似。质量档改变积分精度，不改变阴影范围。取消旧版最多 18 公里的稀疏遮挡采样，以及对天空漫射的两次额外密度衰减。天空漫射来自大气积分的天顶与低空方向；云底概率与粉末项作用于直射光。参考的约 132 米范围在本项目噪声尺度下过于平淡，因此保留更长的局部范围；它仍不是完整远距云影求解。
- **月光**：沿真实月亮方向单独积分云内遮挡与散射，包含月相、大气透射和地球遮挡。白昼跳过月光采样，深夜跳过太阳采样。月光不是原版的均匀蓝色补光。前景云的透射率同时衰减背景月盘。
- **风**：沿用真实秒推进的球面平流，叠加随高度变化的剪切及细节演化。

月光照云增益与大气面板的「月面亮度」独立：前者改变云中的月光，后者只调整月盘。月光能量包含展示用夜间适应增益，不是照度计标定结果；提高月面亮度不会把云染亮。太阳/月亮方向及月相仍由 Cesium Clock 对应的星历决定。

## 对比方法

1. 点击「白昼对比」或「月夜对比」。前者恢复默认云量 0.62、UTC 2026-06-21 17:00；后者使用 UTC 2026-10-26 03:00 的接近满月、云量参数 0.78 和面向月亮的地面机位。两者恢复其余默认天气，并暂停时间与风场。新夜景预设让薄云掠过月盘；提高至 0.85 会形成较厚遮挡，月盘和照云会明显变暗。
2. 切换云层实现；视角与所有公共参数保持不变。
3. 月夜中将「月光照云」从 1 改为 0，可以隔离月光散射贡献。月盘仍显示，照云亮度降低。切回原版时该控制隐藏，原版保留历史光照作为对照。

测试场景 `/tests/cloud-scene.html` 支持 `model=water|cellular`、`time=ISO时间`、`view=moon`、`coverage` 与 `moonLight`。固定渲染缓冲 984×652，关闭相机交互。`storage=rgba8` 强制验证降级路径；`diagnostics` 显示月相、太阳与月亮高度。`atmosphere=off` 可隔离空气透视与大气对云光源的影响，但保留共享显示映射。

## 结构与资源

- `WaterCloudEffect.ts` 提供新密度/光照模型；`CloudComparison.ts` 管理选择、共享参数和风场状态。
- 两个 effect 共用球壳相交、地形深度裁剪、积分与线性辐亮度合成，使用不同密度和光照模块。原版光照仅从 march 中拆出，计算保持不变。
- 两者各自拥有并释放纹理、后处理通道和事件订阅。为即时切换，两套固定纹理同时存在，约 6.28 MiB，另有依视口变化的渲染目标；CPU 噪声缓存共用。未选中通道不执行光线步进。
- 云辐亮度优先存于 RGBA16F，设备不支持半浮点附件/线性采样时回退到原有压缩 RGBA8；重建始终在线性辐亮度中进行。半浮点云目标每像素 8 字节，RGBA8 为 4 字节，均衡档 984×652 场景约增加 1.03 MiB 活跃云目标存储。
- `scene/display.glsl` 是大气与两种云共同的 ACES 拟合曲线和 Gamma 编码，太阳/月亮也先在线性空间相加。共享变化会影响原版云和无云天空的颜色，A/B 比较的是相同环境下的两个云模型。前级天空仍是显示空间输出，云通过解析逆曲线重建有效线性背景；这不是端到端无损 HDR，被截断的太阳高光与原始地表 HDR 仍无法恢复。

## 验证与限制

GPU 页面 `/tests/water-cloud-gpu.html` 使用真实 GLSL 检查零云量、侵蚀上界、厚云核与薄边、风场演化、云下空隙、周期重复、轨道像素足迹稳定性、月相与月光方向、光学厚度衰减，以及三个画质档对均匀介质的相同阴影积分范围。地面射线覆盖 5°–39.5°，包含产品 12° 机位的低空云；密度检测量程扩展到 32/km，避免高密度被 RGBA8 测试附件截断。

当前采用空间重建，没有时域重投影。均衡/流畅档仍可能出现噪点或采样纹理；细节和光照质量不能等同于完整 Sky Pro。没有加入其卷云、月光体积光束或大气月光多重散射。云的天气形态仍为程序化模型；真实地形和 3D Tiles 深度遮挡没有新增专项验收。

本轮同时修复高空海面的大气网格状明暗：相机和射线已转换到椭球缩放后的大气球，地表深度距离却遗漏相同的方向尺度。17000 km 机位可提前截断几十公里空气积分，暴露地球网格。大气与云现在共用 `atmosphereRayDistance`，GPU 回归覆盖近地到轨道的 512 条不同纬度/方向射线，验证转换后的终点误差小于 10 米；固定全球画面网格已消失。

## 上一版性能记录（0d47a14，2026-10-22）

Windows 内置 Chromium，生产构建的固定测试页，实际绘制缓冲 984×652，单个持续渲染标签页，2 秒预热 + 10 秒采样，风和时钟暂停。GPU timer query 测量整个场景。白昼两组使用相同云上机位、默认参数、seed 13 与 UTC 2026-06-21 17:00。

| 场景（均衡） | GPU 平均 | GPU P95 | 平均帧间隔 |
| --- | ---: | ---: | ---: |
| 原版胞状云，白昼云上 | 4.095 ms | 4.868 ms | 4.167 ms |
| 自然水云，白昼云上 | 3.852 ms | 4.512 ms | 4.167 ms |
| 自然水云，月夜对比机位，云量 0.85 | 3.103 ms | 3.831 ms | 4.169 ms |

白昼这一场景的新模型减少约 0.242 ms / 5.9% GPU 时间。两模型的密度分布与覆盖不同，不能当作同密度场下的算法微基准，也不能推广到所有机位。月夜一组时间、机位、云量不同，不与白昼推导加速比。原始结果保存在本地忽略目录 `artifacts/water-comparison-*.json`；本次未重新采样精细档耗时。白昼和月夜的新模型数据包含远景光学厚度过滤。

## 本轮优化验证（2026-10-22）

对照基线为 `0d47a14` 的自然水云，两端均为独立生产构建。Windows 内置 Chromium，同一台机器、单个渲染标签页，984×652 绘制缓冲，均衡档，seed 13，冻结风场和时间；每组 2 秒预热 + 10 秒测量，GPU timer query 测整个场景。白天使用默认参数与 UTC 2026-06-21 17:00；月夜使用 UTC 2026-10-26 03:00、原有 0.85 云量，**没有用降低后的 0.78 展示预设替代性能对照**。

| 场景 | 优化前 GPU 平均 / P95 | 优化后 GPU 平均 / P95 | GPU 平均变化 |
| --- | ---: | ---: | ---: |
| 白昼地面 | 3.256 / 3.984 ms | 2.960 / 3.798 ms | −9.1% |
| 白昼云上 | 3.943 / 4.550 ms | 3.169 / 3.947 ms | −19.6% |
| 月夜，云量 0.85 | 3.229 / 4.612 ms | 2.808 / 4.118 ms | −13.0% |

优化后每组平均帧间隔均约 4.167 ms。三组测量没有性能回退，但密度形状和实际遮挡量已改变，以上是完整场景成本对比，不是相同密度场的算法微基准，也不代表所有设备、机位与画质。原始结果保存在本地 `artifacts/refine-{before,after}-{below,above,night}.json`。

- `npm test`：19 项通过；`npm run build`：通过，保留既有 Cesium bundle 体积提示。
- GPU：14 项水云检查、9 项公共/原版检查通过。薄边 28 个样本、厚核 143 个样本；512 条低空视线中 290 条透射超过 0.5、200 条低于 0.1；轨道坐标终点最大误差约 4.47 米。
- 浏览器：检查白昼云下/云上、日落、满月薄云/厚云、全球视角、流畅和精细档编译、强制 RGBA8 降级、模型切换时保持 0.78 云量与时刻、画质重建、云开关。检查页面未出现渲染或着色器错误。
- 未量化与参考仓库或 Sky Pro 的图像相似度；低档仍有空间抖动颗粒，没有新增时域重投影。
