# 全球尺度体积云

独立 effect：`src/effects/global-clouds/GlobalCloudEffect.ts`，注册 ID `global-clouds`。与 `hillaire-atmosphere` 分开管理；可以独立挂载，也可通过 `CloudLighting` 接口共享太阳、月亮和大气透射率纹理。

## 2026-10-22：全球大气与光照基础修正

本轮从 `9d6524f` 继续，审查基线 `df4ab3c` 之后已有的远景统计云、卷云、球壳排序、深度裁切、WGS84 光程、近景体素和资源释放均保留。根因、固定条件、真实 WebGL 数值及 GPU 成本见 [验证报告](lighting-validation.md)。

- `scatteringPhases` 只计算方向相函数，确认有有效球壳区间后才调用。每个实际有密度的点按当地高度、径向法线与太阳天顶角查询 `skyIrradiance`；不再把相机天空或视线区间中点的天空用于整段云。缓存由大气模块拥有，64×32×2 RGBA8，16 KiB；介质变化时更新，完整天空积分后按 `E/π` 归一化，详见 [大气文档](atmosphere.md)。每个有云点增加两次纹理查询，替代每段两次十步天空积分。
- 日月直射使用真实行星求交与逐点太阳透射，移除 `sunHeight>−0.08` / `moonHeight>−0.03` 门限。高空地平线已下降，负的当地仰角仍可能有效。月相、月光增益及与日光相关的夜间适应仍是独立的展示近似，不充当月亮的几何可见性。
- `voxelShape` 对域 B 的内部深度按 `13.57/7.83` 换为统一单位，`voxelBodyDepth` 随后得到真实公里长度；空区距离仍分别使用两域尺度，密度和 mip 选择不变。
- 自定义日月与大气通过可选 scene-linear 附件进入云 resolve，再统一显示映射。支持 RGBA16F 天空及编码 RGBA8；旧 `CloudLighting.backgroundStage` 默认解释为编码 RGBA8，新提供者用 `backgroundIsHdr` 声明线性存储。没有附件的第三方提供者保留 LDR 恢复近似，不可能从白色显示像素还原截断高光。

仍有明确近似：天空缓存只保留两个漫射角度矩，云内部的环境可见率与散射响应是近似；没有云对天空 LUT 的反向遮挡、跨层投影或完整云气路径追踪。Cesium 地表输入原本是 LDR，逆显示曲线只能给出有效线性值。RGBA8 量化仍有误差，但不通过增加曝光或固定白色环境光补偿。

## 2026-10-22：卫星尺度光学过滤与卷云修正

审查基线为 `df4ab3c`。问题仍存在于该 HEAD：对平均噪声再做密度阈值，不能保持未解析云柱的透射率；高云的细纤维在粗 mip 下几乎消失。修正没有改变 40/64/96 个积分区间、曝光、近景体素、四段球壳排序、深度裁切或 WGS84 射线度量。

- `CloudOptics.ts` 在原 Worker 中生成 32³ RGBA8 光学统计表。256 个固定体素云柱、24 个高度样本用于条件统计，三个轴分别为局部天气覆盖、云型和光学尺度。保存 `E[1-exp(-tau)]`、平均柱深和按可见云量加权的非吸收双流反射率。远景使用归一化的有限厚度体积剖面；0.5–4 km 像素足迹内平滑过渡，4 km 以上不再阈值化平均体素。密度、厚度、斜程仍影响消光。统计介质不满足原始体素的空区距离上界，因此只在这段过渡及远景停用实验性的距离跳过。
- `CirrusField.ts` 先塑造纤维消光、覆盖包络、破碎遮罩，再生成 mip；不把平均噪声重新切成细丝。方向性域的视线导数参与预滤波，沿长丝方向的步进不会按横穿纤维的尺度过滤。高云仍是 9–10.5 km 的有限体积，独立风场、覆盖和高度均保留；光照采用偏前向的冰晶近似相函数。
- 每条有云球壳区间从实际云层位置计算天空补光，消除整颗地球共用相机所在地补光的问题。逐点太阳透射和地球遮挡保留。远景按云柱的条件反射率估计多重散射，避免将平均阴影再次施加于等效稀薄介质；没有加入固定白色环境光。
- 可选 `CloudLighting.backgroundStage` 共享显示映射前的编码天空辐亮度，保持薄云后太阳的 HDR。独立大气开关切换时重新绑定有效附件；没有接入大气的云仍使用原背景恢复路径。

新增固定纹理：光学表 0.125 MiB、卷云 mip 约 1.143 MiB，总固定云纹理约 **13.55 MiB**。额外天空辐亮度目标为 RGBA8，984×652 时约 **2.45 MiB**，不计驱动开销和原有 framebuffer。全部仍由所属 effect/场景阶段释放，销毁中的 Worker 会结束 readiness 等待。

这是统计远景体积和程序化冰云，尚非卫星气象数据或完整路径追踪。远景表以默认细节、3.8 km 厚度的体素集合统计，再缩放柱深；极端厚度、细节参数、掠地视线及特定局地样本可能偏离完整超采样。双流反射、局部高云柱深、层间无投影、透明度加权空气透视和无时域重投影仍为近似。实际验证、固定条件和成本见 [本轮验证报告](satellite-validation.md)。以下历史性能均只对应其注明的旧版本。

## df4ab3c 体素版设计与历史记录

主云默认使用独立 Worker 烘焙的 **128³ RGBA8 三维密度资产**。R 保存体密度，G 保存保守空区距离，B 保存内部深度，A 保存细节形态权重，附完整 mip 链。烘焙时加入连续周期扭曲和多尺度肩部细节；运行时用两个旋转、不同尺度的域组合，天气、云型、侵蚀只削减密度。天气与云柱边界采用连续衰减，避免把云切成直墙。高层卷云与水云对照保持独立。

依据 [Nubis³ 官方讲义](https://d3d3g8mu99pzk9.cloudfront.net/AndrewSchneider/Nubis%20Cubed.pdf) 的以下方法做 WebGL 适配：

- PDF 第 55–56 页：体素与内部距离场。CPU 用三轴精确欧氏距离变换计算空区距离；向下量化，扣除插值支持半径，并限于当前周期单元边界。GPU 额外扣除 mip 足迹，后续区间的足迹变大时收缩复用范围，仅跳过整个确定为空的区间，不改变部分占用区间的积分位置。这是保守 unsigned 距离，不是压缩 SDF sphere tracing。
- 第 113–119 页：丝状/团状细节混合与噪声折叠。复用已有细节采样生成额外近景频率，按足迹消退，不增加高频纹理；主云同时按屏幕与积分子区间预滤波，降低远景颗粒。
- 第 133–147 页：内部 dimensional profile。用内部深度和实际局部密度控制高阶散射概率、天空填充衰减与顺光方向的高阶消光，保留薄边的方向性。主云局部光照域扩至 1.5 km，仍使用 3/5/7 个光照样本；水云保持 600 m。日月共用路径，月相和地球遮挡仍生效。

新增固定纹理约 **9.14 MiB**，主云总固定纹理约 **12.29 MiB**，另计 framebuffer 和大气 LUT。`ready` 在体素就绪或回退完成后结束；`voxelReady` 区分实际成功。Worker 不可用时保留原程序化云，销毁 effect 时终止 Worker、结束等待并释放体素纹理。测试页面支持 `voxels=off` 和 `skip=on/off` 作诊断对照。密集云场实测距离查询成本高于节省的积分成本，默认关闭空区跳过；保留经过验证的实验路径。

这是独立生成的程序化体素资产，**还不是 Nubis 2023 的完整质量复现**：没有流体创作资产库、BC6/压缩 SDF、完整时域重投影、层间投影和远距离光输运。内部深度是未侵蚀体积的局部代理，受天气/实际密度加权，不能替代完整多重散射。近景独立稳定抖动消除了相关采样产生的弧形条纹，但边缘仍有静态颗粒；轨道低画质存在块状预滤波轮廓，尚需专用远景模型。全局仍受预滤波与有限步数影响，不宣称图像相似度百分比。下文旧版性能记录保留其日期/基线语义。

## Nubis 主线：云型与高度分层

### 2026-10-22 体素版验证

`npm test` 22 项、`npm run build` 通过。真实 WebGL2 主云 16 项、水云 14 项回归通过，覆盖密度侵蚀上界、日月响应、云型/层排序、距离跳过和 12 km 非重复形态。1024 条短射线（多 mip 足迹、种子与风状态）共跳过约 167 个空区间，透射差在 RGBA8 探针精度内为 0；这不是任意射线的形式化证明。实际浏览器检查了均衡地面/云顶/月夜、精细穿云、流畅轨道及 RGBA8 回退，无 shader 错误。地面 512 条测试射线中 45 条透射 > 0.5、443 条 < 0.1；这个种子比旧版更密，保留天空空隙不等于所有天气都晴朗。

对照基线 `62b7cba`，两端均为生产构建，同一 Windows 内置 Chromium，单个持续渲染标签页，984×652，均衡画质，seed 13，时间与风冻结。每项预热 2 秒、采样 10 秒，测量整场景 GPU 时间。白昼 UTC 2026-06-21 17:00、云量 0.62；月夜 UTC 2026-10-26 03:00、云量 0.78。默认高云开启，最终版距离跳过关闭。

| 场景 | 旧版 GPU 平均 / P95 | 体素版 GPU 平均 / P95 |
| --- | --- | --- |
| 地面 | 3.184 / 3.984 ms | 3.243 / 4.197 ms |
| 云顶 | 3.236 / 4.136 ms | 3.254 / 3.897 ms |
| 月夜 | 2.834 / 4.116 ms | 2.972 / 4.256 ms |

平均成本分别增加约 1.9%、0.6%、4.9%，不是零成本，也不是跨设备保证。形态不同，因此是实际场景对照，非固定密度微基准。候选版本的距离跳过开/关地面测量为 3.304/2.931 ms；密集场景没有观察到加速收益，故默认关闭。原始结果在忽略目录 `artifacts/voxel-*.json`。未把未完成的时域降噪、流体资产或远景品质列为已验证能力。

云型和海拔是两个独立维度：先用密度剖面控制扁平层云、成片层积云或垂直发展的积云，再把它放进指定高度范围。不能只把同一种噪声移动到不同高度，就认为得到了不同云型。

[Nubis 2017](https://www.guerrilla-games.com/read/nubis-authoring-real-time-volumetric-cloudscapes-with-the-decima-engine) 的 [Density Model 讲义](https://d3d3g8mu99pzk9.cloudfront.net/AndrewSchneider/Nubis-Authoring-Realtime-Volumetric-Cloudscapes-with-the-Decima-Engine-Final.pdf) 展示了云型相关的高度梯度，包括层云梯度。[Nubis, Evolved 是 2022 年](https://www.guerrilla-games.com/read/nubis-evolved) 的演进；[2023 年的 Nubis³](https://www.guerrilla-games.com/read/nubis-cubed) 则转向体素建模、流体生成资产和压缩距离场加速。这里采用适合 WebGL 全球场景的程序化体素与高度分层，不宣称复现后者的流体资产与创作系统。

| 层 | 本项目的建模 | 默认高度与控制 |
| --- | --- | --- |
| 主云层 | 天气场 + 连贯云柱空隙 + 体素主体 + 侵蚀；云型改变有效云顶、垂直剖面 | 1.5–5.3 km 的最大范围；`type=0` 天气混合，`1` 层云，`2` 层积云，`3` 积云 |
| 高层卷云 | 独立覆盖包络 + 方向性纤维 + 局部弯曲/断裂 + 有限厚度的稀薄介质 | 9–10.5 km；独立 `highCoverage`、`highBase`、`highThickness`、`highWind` |

层云、层积云、积云的剖面支持上限分别约为主云层厚度的 26%、58%、100%；实际云顶还受天气和侵蚀影响。高度是可编辑的展示参数，不是全球统一的气象分类线。当前同时渲染一层主云和一层卷云；还没有任意数量的独立中层堆栈。

高层卷云复用现有噪声纹理，但采用不同的各向异性域、覆盖包络和消光。世界坐标域没有经纬度拼接缝；纤维在所选方向轴的极区会缩短，尚未实现全球气象风向场。云量为 0 时完全跳过该层；修改主云层后，高云底自动保持在主云层范围顶部至少 0.5 km 以上，界面同步显示实际值。风场分别积累，暂停/重置/切换模型都保留一致语义。

渲染在同一个体积通道中对最多四个球壳路径排序，不增加一套全屏 framebuffer 或新的噪声纹理。地面向上是低云在前，轨道向下是高云在前，掠地射线可依次穿越“高近、低近、低远、高远”。均衡画质主云仍为 64 个区间，高云按路径长度使用 16–48 次采样且不做细分；高云采用中点积分，噪声同时按屏幕足迹与视线区间宽度预滤波，减少斜视颗粒。高云光照用有界局部柱深，主云采用从水云方案合并的日月局部散射。

这两层有正确的视线遮挡，但尚无层间投影；空气透视仍使用合并后的透明度加权代表距离，并非完整的云气混合积分。极薄纤维和地平线可能有欠采样颗粒，不能把这个增量视为最终照片级卷云。

本版本选择每帧低分辨率积分和深度感知重建，避免长历史带来的移动拖影。没有实现 Sky Pro / Nubis 完整时域重投影。对于全球漫游，这是显存、集成复杂度和画质之间的初始折中，不代表所有设备和天气条件下的最优解。

## 数据与渲染

- 1024×512 RGBA8 天气图：在三维单位球面上计算覆盖、云型和两个区域尺度。区域噪声的哈希周期大于整颗地球，结果烘焙到全球纹理；经度重复采样仅连接日期变更线，不再用小纹理反复铺满大陆。天气种子可调，默认 13；只在初始化或更换种子时生成。
- 64³ RGBA8 胞状噪声及 mip 作为近景细节源：坐标扭曲、旋转和不共周期的尺度混合，打破原来的 12 km 可见重复。区域分布不再直接采样周期为 900/180 km 的小纹理；高度贯通的云团掩码保留云下空隙。CPU 噪声数据复用，GPU 纹理由每个 effect 独立拥有。
- WGS84 极轴归一化到等效球体，使用 km 积分。每层外球减内球得到最多两段路径，两层最多四段，按每条射线的实际距离排序后前向积分，并与地球实体、Cesium 场景深度裁剪。支持云下、云中、层间、高云上方和轨道外观察。
- 主云层与水云对照共用 `droplet-lighting.glsl`：流畅/均衡/精细使用 3/5/7 个光照样本，水云/回退路径积分固定 600 米局部锥形域，体素主云使用 1.5 km，100 米以外使用未侵蚀密度。三个双瓣 HG 阶次近似多重散射，天空漫射来自大气积分，取消历史版本的两次额外环境遮蔽。高层云使用有界局部柱深近似而不额外执行光照锥形步进。太阳通量、月夜适应仍有展示校准，这不是完整路径追踪。
- 共用 Hillaire 的透射率、多重散射 LUT、介质参数和曝光。以透明度加权距离计算 12 步空气透视，得到 RGB 透射与入散射，替代首版固定蓝色雾。两层均接入真实月亮方向、月相和月光增益，直射光受地球遮挡与大气透射影响。
- 40/64/96 个积分区间，按距离和足迹最多细分 2/3/4 次，分别使用 50%/65%/100% 的宽高分辨率。近地长路径使用二次采样分布，透射率足够低后提前结束。固定空间抖动保持暂停后的稳定性。
- 低分辨率射线通过连续地表的四点深度插值进行裁剪，避免使用邻近全分辨率射线的深度导致轨道云层网格状破洞；深度断层保持最近点采样。再用全分辨率深度/透明度/颜色感知的 3×3 双边重建，云颜色使用预乘 alpha 覆盖大气结果。风场按真实秒平流；Cesium 时间加速只影响天体和光照，不会让云在 3600× 时瞬间绕地球移动。

积分始终在线性辐亮度空间进行；云目标优先使用线性 RGBA16F，不支持时回退到压缩 RGBA8，重建时逐 texel 解码再插值。合成后使用与大气共享的 ACES 拟合/Gamma 显示映射。固定云纹理约 12.29 MiB（天气 2 MiB、胞状噪声及 mip 约 1.14 MiB、体素及 mip 约 9.14 MiB），另加随视口变化的体积/合成 framebuffer；大气 LUT 由大气 effect 拥有并共享。销毁时释放云纹理、post-process stages 与事件监听。

## 使用

```ts
const clouds = new GlobalCloudEffect({
  sunDirection: () => atmosphere.sunDirection,
  moonDirection: () => atmosphere.moonDirection,
  moonFraction: () => atmosphere.moonFraction,
  transmittance: () => atmosphere.transmissionTexture,
  atmosphereEnabled: () => atmosphere.enabled,
  multipleScattering: () => atmosphere.multipleScatteringTexture,
  medium: () => atmosphere.mediumParameters,
  exposure: () => atmosphere.parameters.exposure,
});
// 先挂载 atmosphere，再挂载 clouds。
clouds.mount({ viewer, onStatus: console.info });
clouds.updateParameters({ coverage: 0.62, base: 1.5, thickness: 3.8, type: 0,
  highBase: 9, highThickness: 1.5, highCoverage: 0.35, highWind: 48, seed: 13 });
clouds.setQuality('medium');
clouds.view('inside');
// 使用结束时先销毁 clouds，再销毁提供纹理的 atmosphere。
clouds.destroy();
```

实验室切换回龙卷风时默认关闭全球云，避免原龙卷风机位被全球云层覆盖；可用独立开关重新启用。两个后处理体积并没有统一的逐样本透明排序，不保证重叠体积的精确合成。

## 已知边界

这是程序化全球天气视觉效果，不是真实天气预报。当前是两个互不重叠的可调球壳：主云层云型剖面与独立高层卷云；尚无第三个独立中层、雷暴闪电、降水或向地表投射的云影。局部 600 米光照和高云柱深不求解跨云层阴影或日落长阴影；高云暂用通用双瓣相函数，并非冰晶微物理。多重散射与月光仍是近似。空气透视使用云的加权代表距离，没有逐采样点积分整个云/气混合介质。低画质的地平线和稀薄边缘可能出现采样噪声。

球壳与近地空间使用浮点公里坐标和 WGS84 缩放近似，不适用于厘米级遮挡。Cesium 前级画面已经显示映射：当前对它做与大气曝光对应的逆映射，以有效线性背景参与云合成；被前级截断的太阳高光和原始地表 HDR 无法恢复。因此仍不等同于整个 Cesium 渲染器端到端的线性 HDR 管线。

## 第二轮：水云形态、云下空隙与风场（2026-10-22）

在 `baa3372` 的线性光照修正之后，精细档依然呈现过软的雾状云体。本轮继续对照本地 Sky Pro 的 `density.ts`、`cloudDensitySampler.ts`、`noiseProfiles.ts`、`Clouds.ts` 和月夜预设，理解密度边界、多尺度胞状噪声、光线采样以及平流/剪切/演化的分工。代码与噪声重新实现，没有复制商业源码、噪声文件或预设常量。

- 全球云改用独立 `CumulusNoise.ts`：64³ RGBA8 胞状噪声，四组频率生成多个层次的云瓣，包含完整六级 mip。固定纹理约 **3.14 MiB**（天气 2 MiB，噪声及 mip 约 1.14 MiB）。原龙卷风的 48³ 噪声不变。
- 密度从宽范围线性稀雾改为有限软边界与厚实内部。形状、边缘侵蚀和像素足迹分别控制；显式 `textureLod` 避免分支内部隐式导数问题。新增贯穿高度的区域云团掩码：不同高度的随机空隙不会再叠成默认地面视角的连续云盖。高云量仍允许阴天，不保证任意地点、种子都有蓝天。
- 主光线仍使用 40/64/96 个区间，根据区间长度与像素足迹细分，最多分别 2/3/4 次（上限 80/192/384 样本）。不再把区间中点无云错误地当作整个区间为空。近处太阳光线改为几何递增间隔，改善小云瓣的自遮挡；相函数提到每条视线计算一次。地表反射补光保留有限贡献，避免云底因局部密度而完全失去补光。
- 风速除了全球平流，还驱动高度剪切和不同速度的噪声演化。它是程序化风驱动形变，不是 Navier–Stokes 云动力学。24 m/s 按真实秒推进，公里尺度云团短时间内不会大幅位移；提高风速能更快看见变化。暂停同时冻结平流和演化，重置清空两者积累。
