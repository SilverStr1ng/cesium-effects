# 全球尺度体积云

独立 effect：`src/effects/global-clouds/GlobalCloudEffect.ts`，注册 ID `global-clouds`。与 `hillaire-atmosphere` 分开管理；可以独立挂载，也可通过 `CloudLighting` 接口共享太阳、月亮和大气透射率纹理。

## 方案选择

| 参考 | 采用的思路 | 本项目的取舍 |
| --- | --- | --- |
| Three.js Sky Pro v2.2.1 | 对照其线性 HDR 积分、天空环境光与大气透射/入散射合成流程 | 首版只阅读文档；后续按照用户要求查看 `cloudLighting.ts`、`CloudMaterial.ts`、`CloudCompositeMaterial.ts` 等源码以分析差异。没有移植商业源码、常量表或素材。 |
| [Nubis³, SIGGRAPH 2023](https://www.guerrilla-games.com/read/nubis-cubed) | 可穿行体积、内部散射与边缘照明 | 首版的低分辨率全球阴影缓存无法表示公里级云团，现改为实际密度场的局部光线采样。这里并非 Nubis 实现，也没有其 BC6 体素资产、压缩 SDF 或创作管线。 |
| [Advances in Real-Time Rendering 2023](https://www.advances.realtimerendering.com/s2023/index.html) | 云的采样预算、空区跳过与远景细节控制 | 精确跳过球壳外部，天气/高度为零时不读细节纹理，按像素覆盖范围淡出高频噪声；不把密度阈值步进称作 SDF sphere tracing。 |

本版本选择每帧低分辨率积分和深度感知重建，避免长历史带来的移动拖影。没有实现 Sky Pro / Nubis 完整时域重投影。对于全球漫游，这是显存、集成复杂度和画质之间的初始折中，不代表所有设备和天气条件下的最优解。

## 数据与渲染

- 1024×512 RGBA8 天气图：在三维单位球面上计算覆盖、云型和两个区域尺度。区域噪声的哈希周期大于整颗地球，结果烘焙到全球纹理；经度重复采样仅连接日期变更线，不再用小纹理反复铺满大陆。天气种子可调，默认 13；只在初始化或更换种子时生成。
- 64³ RGBA8 胞状噪声及 mip 作为近景细节源：坐标扭曲、旋转和不共周期的尺度混合，打破原来的 12 km 可见重复。区域分布不再直接采样周期为 900/180 km 的小纹理；高度贯通的云团掩码保留云下空隙。CPU 噪声数据复用，GPU 纹理由每个 effect 独立拥有。
- WGS84 极轴归一化到等效球体，使用 km 积分。外球减内球得到最多两段云层路径，并与地球实体、Cesium 场景深度裁剪。支持云下、云中、云上和轨道外观察。
- 移除粗糙的全球阴影 atlas。流畅/均衡/精细分别使用 3/5/7 个渐扩光线样本，积分与相机一致的密度场；加两个向上样本控制天空环境遮蔽。光学厚度使用 Beer 衰减，三个逐步变宽的 HG 散射阶次近似多重散射。太阳通量仍有视觉校准增益，这不是完整路径追踪。
- 共用 Hillaire 的透射率、多重散射 LUT、介质参数和曝光。以透明度加权距离计算 12 步空气透视，得到 RGB 透射与入散射，替代首版固定蓝色雾。月光仍是简化环境项。
- 40/64/96 个积分区间，按距离和足迹最多细分 2/3/4 次，分别使用 50%/65%/100% 的宽高分辨率。近地长路径使用二次采样分布，透射率足够低后提前结束。固定空间抖动保持暂停后的稳定性。
- 低分辨率射线通过连续地表的四点深度插值进行裁剪，避免使用邻近全分辨率射线的深度导致轨道云层网格状破洞；深度断层保持最近点采样。再用全分辨率深度/透明度/颜色感知的 3×3 双边重建，云颜色使用预乘 alpha 覆盖大气结果。风场按真实秒平流；Cesium 时间加速只影响天体和光照，不会让云在 3600× 时瞬间绕地球移动。

积分始终在线性辐亮度空间进行；中间 RGBA8 纹理压缩存储 HDR，重建时逐 texel 解码再插值，合成后统一做曝光映射。固定云纹理约 3.14 MiB（天气 2 MiB、胞状噪声及 mip 约 1.14 MiB），另加随视口变化的体积/合成 framebuffer；大气 LUT 由大气 effect 拥有并共享。销毁时释放云纹理、post-process stages 与事件监听。

## 使用

```ts
const clouds = new GlobalCloudEffect({
  sunDirection: () => atmosphere.sunDirection,
  moonDirection: () => atmosphere.moonDirection,
  moonFraction: () => atmosphere.moonFraction,
  transmittance: () => atmosphere.transmissionTexture,
  atmosphereEnabled: () => atmosphere.enabled,
  multipleScattering: () => atmosphere.multipleScatteringTexture,
  medium: () => atmosphere.mediumParameters,
  exposure: () => atmosphere.parameters.exposure,
});
// 先挂载 atmosphere，再挂载 clouds。
clouds.mount({ viewer, onStatus: console.info });
clouds.updateParameters({ coverage: 0.62, base: 1.5, thickness: 3.8, seed: 13 });
clouds.setQuality('medium');
clouds.view('inside');
// 使用结束时先销毁 clouds，再销毁提供纹理的 atmosphere。
clouds.destroy();
```

实验室切换回龙卷风时默认关闭全球云，避免原龙卷风机位被全球云层覆盖；可用独立开关重新启用。两个后处理体积并没有统一的逐样本透明排序，不保证重叠体积的精确合成。

## 已知边界

这是程序化全球天气视觉效果，不是真实天气预报。当前为单个可调厚度球壳，没有独立高空卷云层、雷暴闪电、降水或向地表投射的云影。太阳光线采样最长 32 km，少量锥形采样不能精确求解日落长阴影；多重散射与月光仍是近似。空气透视使用云的加权代表距离，没有逐采样点积分整个云/气混合介质。低画质的地平线和稀薄边缘可能出现采样噪声。

球壳与近地空间使用浮点公里坐标和 WGS84 缩放近似，不适用于厘米级遮挡。Cesium 前级画面已经显示映射：当前对它做与大气曝光对应的逆映射，以有效线性背景参与云合成；被前级截断的太阳高光和原始地表 HDR 无法恢复。因此仍不等同于整个 Cesium 渲染器端到端的线性 HDR 管线。

## 第一轮修正验证（baa3372，历史记录）

`npm test`：17 项通过，新增种子确定性/差异检查并检查烘焙纹理的极点行。`npm run build` 通过。运行开发服务器后访问 `/tests/cloud-gpu.html`：在实际 WebGL2 中执行生产 GLSL，检查 900 km 区域重复、12 km 局部重复、亮暗样本的线性积分以及零云量背景保持；结果显示于 DOM，可通过浏览器自动读取。

修复前，900 km 平移的采样 RMS 差为 **0**，亮暗混合输出 0.45882，而参考值为 0.71350。修复后两项通过；新加入的局部重复检查也通过。这个检查不能代表与参考产品的图像相似度，但能捕获已定位的具体缺陷。

修正版最终生产构建另外检查了天气种子切换（13 → 150）、重置恢复 13、云上/全球视角、日落/夜间和零云量；浏览器未记录 error/warn。均衡档近景细节仍偏柔和，全球云型仍是程序化覆盖，不能等同于真实天气系统的气象结构。

### 首版历史性能（60cde86，非当前版本）

## 第二轮：水云形态、云下空隙与风场（2026-10-22）

在 `baa3372` 的线性光照修正之后，精细档依然呈现过软的雾状云体。本轮继续对照本地 Sky Pro 的 `density.ts`、`cloudDensitySampler.ts`、`noiseProfiles.ts`、`Clouds.ts` 和月夜预设，理解密度边界、多尺度胞状噪声、光线采样以及平流/剪切/演化的分工。代码与噪声重新实现，没有复制商业源码、噪声文件或预设常量。

- 全球云改用独立 `CumulusNoise.ts`：64³ RGBA8 胞状噪声，四组频率生成多个层次的云瓣，包含完整六级 mip。固定纹理约 **3.14 MiB**（天气 2 MiB，噪声及 mip 约 1.14 MiB）。原龙卷风的 48³ 噪声不变。
- 密度从宽范围线性稀雾改为有限软边界与厚实内部。形状、边缘侵蚀和像素足迹分别控制；显式 `textureLod` 避免分支内部隐式导数问题。新增贯穿高度的区域云团掩码：不同高度的随机空隙不会再叠成默认地面视角的连续云盖。高云量仍允许阴天，不保证任意地点、种子都有蓝天。
- 主光线仍使用 40/64/96 个区间，根据区间长度与像素足迹细分，最多分别 2/3/4 次（上限 80/192/384 样本）。不再把区间中点无云错误地当作整个区间为空。近处太阳光线改为几何递增间隔，改善小云瓣的自遮挡；相函数提到每条视线计算一次。地表反射补光保留有限贡献，避免云底因局部密度而完全失去补光。
- 风速除了全球平流，还驱动高度剪切和不同速度的噪声演化。它是程序化风驱动形变，不是 Navier–Stokes 云动力学。24 m/s 按真实秒推进，公里尺度云团短时间内不会大幅位移；提高风速能更快看见变化。暂停同时冻结平流和演化，重置清空两者积累。

### 回归与画质检查

18 项 CPU 测试通过；新增 mip 能量/尺寸验证。实际 WebGL2 页面 `/tests/cloud-gpu.html` 的 8 项检查通过，包括保留上一轮的周期重复、线性光照和零云量检查，以及侵蚀上界、厚实云核、风场演化与云下天空空隙。固定默认地面方向集的 512 条射线中，165 条透射率大于 0.5，332 条小于 0.1；这是该固定场景的回归数据，不是全球云量百分比。冻结整体平流后，演化参数仍改变密度，验证其不只是整体移动。

新增开发用 `/tests/cloud-scene.html?benchmark&view=above&quality=medium`，固定相机/时间/种子/风场并关闭相机输入，画布 CSS 尺寸 984×652。`view` 支持 above/below/inside/global，`quality` 支持 low/medium/high。页面不进入常规生产 bundle。固定场景可单独构建用于生产性能对照；使用推荐分辨率并固定 resolutionScale = 1；本次前后实际绘制缓冲均为 **984×652**，不受浏览器面板宽度变化影响。

以上性能数据已包含最后加入的 3×3 双边重建和更宽的空间采样抖动；它们减轻厚云表面的规则条纹，同时保留地形和云轮廓边界。当前没有时域重投影；均衡档仍可能在云边缘、地平线看到柔化或采样纹理；流畅档云内视角的欠采样条纹更明显，不适合近距离画质展示。长阴影、月光和多重散射仍是近似，未声称达到 Sky Pro 的完整质量。真实地形、3D Tiles 的遮挡仍需专项验证。

实际浏览器确认了默认云下空隙、120 m/s 风驱动形变、暂停与重置，以及放大太阳和调亮后的满月显示。日月参数独立归入大气 effect。
