# 龙卷风验证记录

日期：2026-10-22。Cesium 1.146.0，Windows 本机内嵌 Chromium / WebGL 2。

## 视觉目标与结果边界

参考为 [BV13WMB6SEEf，3:42](https://www.bilibili.com/video/BV13WMB6SEEf/?t=222)。观察帧停在约 221.44 秒：大面积冷白/青色翻卷云团、较暗中心空腔，主体占据 UE 视窗大部分面积。

本轮将原来窄漏斗的 2.4 km 体积域扩至 7.2 km，重新塑造不对称环状云冠、底部漏斗与尘雾；加入周期性三维云噪声、缓存方向光学深度、细节照明和近景俯视机位。默认近景按钮用于观察云冠，侧面定位用于观察整体。

**“视觉差距小于 5%”未完成量化验收。** 视频画面包含 UE 编辑器界面，缺少原工程的镜头、密度场、光照和模拟状态，像素差无法直接代表特效相似度。当前云团细节、光照色彩、时变翻卷仍与原视频有差异，不能标注为 95% 复刻。没有将视频截图或视频资源作为项目资产。

建议后续视觉验收固定参考时间窗和主体裁剪区域，统一相机/投影、分辨率与曝光，分别比较轮廓、空腔、纹理频谱和运动，再由用户确认感知相似度。SSIM 等分数也不能直接换算成“差距百分比”。

## 性能测量

入口：`/?benchmark`。默认参数、均衡画质、实验底图，视口 1440×1000，Cesium drawing buffer 1144×932，96 个射线步进，体积阶段分辨率系数 0.8。使用同一侧视定位机位：heading 8°，pitch −12°，距离 6600 m，目标高度 1320 m。模拟持续运行；2 秒预热后采样 10 秒。新版本记录相机向量，可在 JSON 中检查测量前后是否变化。

| 指标 | 原版 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 平均帧间隔 | 4.1706 ms | 4.1672 ms | −0.08% |
| P95 帧间隔 | 4.3000 ms | 4.3000 ms | 0% |
| 平均 CPU 提交耗时 | 0.7525 ms | 0.7635 ms | +1.46% |
| 平均整场景 GPU 耗时 | 2.7192 ms | 2.9155 ms | +7.22% |
| P95 GPU 耗时 | 3.2710 ms | 3.5264 ms | +7.81% |

原始数据：[before](performance-before.json)、[after](performance-after.json)。GPU 使用 `EXT_disjoint_timer_query_webgl2` 异步查询，不把 CPU 提交时间当作 GPU 时间。帧间隔接近本机 240 Hz 调度上限，因此 GPU 时间更适合判断成本变化。CPU 提交时间不包含 Worker 求解。单机单次 10 秒测量具有噪声；以上结论不外推到其他设备、画质或默认近景机位。

体积域变宽使覆盖像素增加；用一次生成的 48³ 四通道噪声纹理和 Worker O(voxels) 光照扫描，替换原来每步重复计算的程序噪声和额外阴影采样。没有增加均衡档网格、步数或分辨率。

## 自动化验证

- 8 项 `npm test` 通过：D3Q19 守恒矩、静止态、实际涡旋/上升流、极端参数 300 步稳定性、atlas 寻址、重置确定性、光学深度累积/清空、噪声周期边界/确定性。
- `npm run build` 通过 TypeScript 和 Vite 生产构建。仍有 Cesium bundle 体积提示。
- `npm audit --omit=dev`：0 vulnerabilities。
- 实际浏览器：生产构建加载无控制台错误；低/中/高画质重建可用；暂停时两次云体区域截图字节一致、迭代不再增加；关闭后底图恢复，重新开启和重置可用；390 px 窄屏无横向溢出。

## 已知范围

这是带实际 LBM 输运的艺术控制体积特效。三维噪声动画不等于更高分辨率的流体求解；体积只进行近似自遮蔽，没有地面投影阴影。低画质会损失细节，透明物体的排序仍受 Cesium 后处理限制。Cesium 内部纹理 API 隔离在适配层，升级版本需重新检查。
